# Μιχαήλ Σ. Μιχαλακόπουλος

Συγγραφέας και ερευνητής της ελληνικής λογοτεχνίας.

Γράφω διηγήματα, δοκίμια και ιστορικά μελετήματα, με ιδιαίτερο ενδιαφέρον για τη λαϊκή παράδοση, τις οικογενειακές μνήμες και την τοπική ιστορία της Αρκαδίας. Ασχολούμαι επίσης με τη φιλολογική και γλωσσική επιμέλεια.

### Οι Ιστορίες που Έλεγε η Γιαγιά

Η συλλογή περιλαμβάνει 16 διηγήματα, κυρίως εμπνευσμένα από τη λαϊκή παράδοση της ορεινής Γορτυνίας, στην Αρκαδία. Οικογενειακές αφηγήσεις, μνήμες, θρύλοι και θρησκευτικά έθιμα αποτελούν τον πυρήνα της. Συνοδεύεται από επίλογο, γλωσσάρι, βιογραφικό σημείωμα και ευχαριστίες.

[Διαβάστε τη συλλογή «Οι Ιστορίες που Έλεγε η Γιαγιά»](https://michelis2023.github.io/oi-istories-pou-elege-i-giagia/)

### Γοτθικά διηγήματα

[Διαβάστε τη συλλογή γοτθικών διηγημάτων](https://michelis2023.github.io/short-stories/)

- Νυχτερινή Βάρδια στο Σανατόριο του Μαινάλου
- Τα Σμυρδάκια
- Το Χέρι κάτω από το Χώμα
- Το Ζοφερόν Μυστικόν του Αγίου Ταξιάρχη
